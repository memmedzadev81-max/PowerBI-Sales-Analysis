# Power Query Addımları

1. CSV-ni Get Data > Text/CSV ilə yükləyin
2. OrderDate sütununu Date tipinə çevirin
3. Discount% sütununu Percentage formatına salın (və ya /100 edin)
4. SalesAmount və Cost-u Decimal Number edin
5. Boş sətirləri silin (əgər varsa)
6. Region və Category üçün sorted columns yarada bilərsiniz

Optional:
- Duplicate column for Month/Year extraction
- Conditional column for High/Low value orders (SalesAmount > 1000)

Mən adətən bu addımları edəndən sonra Close & Apply basıram.
