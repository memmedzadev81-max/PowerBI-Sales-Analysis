# Power BI Report Structure

## Page 1: Overview

**KPI Cards (üst sıra):**
- Total Sales
- Total Profit
- Profit Margin %
- Total Orders
- Average Order Value

**Visuals:**
- Line chart: Sales by Month (OrderDate)
- Map or Bar chart: Sales by Region
- Donut chart: Sales by Category
- Table: Top 5 Products by Sales

**Filters:** Region, Category, Date range (slicer)

## Page 2: Product Analysis

- Clustered bar chart: Sales & Profit by Category
- Treemap: Product performance
- Matrix: Category x Region matrix with Sales
- Scatter: Quantity vs SalesAmount (bubble size = Profit)

## Page 3: Customer Insights

- Bar chart: Sales by Customer
- Card: Unique Customers count
- Table with conditional formatting: Customer details

## Page 4: Trends & Forecast (optional)

- Area chart for monthly trends
- YoY comparison

## Rənglər və stil
- Primary color: #0078D4 (Microsoft blue)
- Positive: green
- Negative: red
- Font: Segoe UI

Mən bu strukturu sadə və oxunaqlı tutmağa çalışdım. Əlavə slicer və bookmarks da əlavə etmək olar.
